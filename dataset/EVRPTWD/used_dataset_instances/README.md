# Used dataset instances (easy wide)

RC Cus_100 from EVRP-TW-D **unanchored**, selected for an **easy warm-start** study.

- **100 train / 10 test** (no validation)
- Train: **100 easiest RC wide** by ease score
- Test: **5 wide** (next-easiest held-out) + **5 narrow** (easiest narrow)
- Seed **42**

See `split_manifest.json` for the exact lists.
